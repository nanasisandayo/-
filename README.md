# 簿記カードゲーム α スマホ版

iPhoneのSafariなど、現代のブラウザで遊ぶための静的Web版です。外部ライブラリは使っていません。

## 収録内容
- 2人対戦の交代プレイ
- サイコロ1個目: 1〜10
- サイコロ2個目: 1〜4
- 取引金額 = 1個目 × 2個目 × 1,000円
- 取引内容はゲーム側から指定せず、プレイヤー自身が決定
- 勘定科目をタップで借方/貸方へ追加、PCではドラッグ＆ドロップも可能
- 複合仕訳に対応した複数行入力
- 借方・貸方一致と今回の金額一致を判定
- 仕訳履歴と会社の数字を表示
- 決算時に純利益・純資産・収益・費用・暫定スコアを表示
- 黒字倒産判定（α版では決算時に負債を支払う前提）
- PWA用manifest / Service Worker付き

## iPhoneで使う方法
ZIPを展開しただけではSafariはHTMLをアプリとして実行しません。Webサーバー上に `web` フォルダの中身を置いて、そのURLをSafariで開いてください。

公開後はSafariの「共有」→「ホーム画面に追加」で、アプリのように起動できます。
